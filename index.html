A privacy-focused emergency blood donation app that connects patients with nearby, compatible, verified donors through real-time SOS alerts.

Seven core screens

Emergency SOS, map search, donation posts, eligibility checker, secure messaging, gamification and the BloodBot assistant.

What it does

Built around speed in an emergency and privacy for donors.

Real-time SOS alerts

A patient's request is pushed instantly to compatible donors within a set radius using Firebase Cloud Messaging, with live acceptance and ETA tracking.

Verified donors

Donors verify their identity by scanning their CNIC; on-device ML Kit text recognition reads the card so fake profiles are filtered out.

Eligibility checker

A short health questionnaire (age, weight, last donation, recent illness) decides whether a donor can mark themselves available.

Privacy-first messaging

Phone numbers stay hidden. Patients, donors and NGOs talk through encrypted in-app chat and share details only with consent.

Rewards and leaderboard

Points, levels and badges for confirmed donations and quick responses keep regular donors engaged.

BloodBot NLP assistant

Answers common donation questions in plain language and can find verified donors near a hospital on request.

How it works

A React Native client on a serverless Firebase backend.

App

  • React Native 0.79 with React Navigation (bottom tabs + native stack)
  • Google Maps and device geolocation for nearby-donor search
  • ML Kit text recognition for CNIC verification
  • Image picker, toast notifications and animated UI

Backend

  • Firebase Auth for sign-in and verified accounts
  • Firestore with security rules and composite indexes for fast donor matching
  • Cloud Messaging for real-time SOS push alerts
  • Cloud Storage for documents and images; Cloud Functions for server logic

Blood Bridge is a native Android/iOS app, so it runs on phones rather than in the browser. This page showcases the app's screens, features and a recorded demo.
